## 🚀 Key Modules & Capabilities

### 1. 📄 Unity 2.0 Workspace (Rebranded from Notion)
* **Dynamic Block System**: Text headings (H1/H2/H3), bullet lists, checklists, syntax-highlighted code snippets, callouts, and dynamic tables.
* **Markdown Importer/Exporter**: 1-click import of `.md` specs and real-time Markdown exporting.
* **Cover & Icon Studio**: Custom vector SVG icons and retro geometric patterns.
* **Deep AI Context Ingestion**: Documents automatically indexed into the local RAG knowledge base.

### 2. 📹 Moveable Video Camera & P2P Screensharing
* **Draggable Camera PiP**: Freely moveable floating viewport with bounding limits and glassmorphism styling.
* **📍 Default Left Corner Snap**: Instant docking to the bottom-left corner with 1 click or `Ctrl+Shift+S`.
* **⛶ 1-Click Fullscreen**: Toggle full workspace dimensions instantly.
* **🔴 Integrated Screen Recorder**: Live screen/camera recording with custom retro watermark composite.
* **⚡ 100% P2P Streaming**: WebRTC & BroadcastChannel direct mesh (zero Firebase storage/bandwidth consumed).
* **☁️ Free VM Session Logger**: Edge telemetry logs active streaming sessions (`GCP-VM-SESS-XXXX`) to the Always-Free VM.

### 3. 💰 4-Stage Commercial CRM Pipeline
* **Financial Lifecycle Stages**: `Check-in` ➔ `Quoted` ➔ `Followed Up` ➔ `Paid / Won`.
* **Dynamic SVG Telemetry**: Real-time pipeline value forecasting and stage probability calculation.
* **AI Proposal Generator**: Generates commercial scopes and financial milestone proposals in 1 click.

### 4. ⚡ Agile SCRUM Sprint Hub
* **Sprint Kanban**: Backlog, `⚡ Busy With` (active sprint in progress), and `✅ Completed` (3 completed reference stories).
* **Metrics Dashboard**: Automated story point burndown and velocity tracking.

### 5. 🧠 Local Tiny AI & Semantic RAG Vector Cache
* **Local Tiny AI (In-Cache / Nano)**: Runs on-device via `window.ai` or local in-cache neural engine (0 network calls, 0ms latency).
* **Local RAG Vector Cache**: Chunks and indexes docs, deals, and tasks for context-enriched generation.
* **☁️ 1-Click Free Cloud VM Backup**: Backs up RAG vector knowledge to the Always-Free GCP VM & Cloud Storage (`gs://ionity-storage-root/rag-cache.json`).

### 6. 🔑 Remote SSH Terminal & WebSSH Bridge
* **1-Click Google Cloud Web SSH**: Opens Google Web SSH directly into `ionity-central-vm`.
* **CLI Terminal SSH**: Copy-ready `gcloud compute ssh` and direct `ssh root@34.120.45.89` commands.
* **In-Browser WebSSH Daemon (`ttyd`)**: Automated installer (`tools/setup-webssh-ttyd.sh`) for interactive browser terminals.

## 💻 Local Development Setup

Clone the repository and run locally in seconds:

```bash
# 1. Clone Repository
git clone https://github.com/Ionity-Global-Pty-Ltd/ionity-central.git
cd ionity-central

# 2. Start Local Server (Python / Node / any static server)
python -m http.server 8080
# or
npx serve . -p 8080
```

Open your browser at: **`http://127.0.0.1:8080/`**

## ☁️ Deployment Guide

### Option A: Deploy to Firebase Web Hosting (Recommended)

```powershell
# 1. Login to Firebase
firebase login

# 2. Deploy to Live Production
firebase deploy --only hosting --project ionity-root-system
```

Production URL: **`https://ionity-root-system.web.app`**

### Option B: Provision Always-Free Google Cloud VM

Run the automated orchestrator in PowerShell:

```powershell
.\tools\deploy-gcp-vm.ps1 -ProjectId "ionity-root-system" -Zone "us-central1-a"
```

The script automatically:
1. Enables Compute Engine and Cloud Storage APIs.
2. Configures UFW firewall rules (Ports 22, 80, 443).
3. Creates a 5GB Standard Cloud Storage bucket.
4. Provisions an `e2-micro` VM (2 vCPUs, 1GB RAM) with a 30GB Standard Persistent Disk in `us-central1-a`.
5. Uploads application files and executes the bootstrap script (`deploy-gcp.sh`) configuring a **2GB swapfile**, Nginx reverse proxy, and Let's Encrypt SSL.
